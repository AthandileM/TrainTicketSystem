Train Ticket Booking System:
A simple Java based train ticket booking system that allows users to enter passenger and journey details, select a supported route and calculate the ticket cost then confirm payment.
Features:
Allows the user to enter passenger details.
Allows the user to enter departure and destination.
Allows the user to select a supported train route.
Validates the selected route.
Calculates the total ticket price based on the route and number of tickets entered.
Confirms payment before completing the booking.
Generates a random reference number.
Allows the user to make another booking using a loop.
Technologies used:
Java,
NetBeans.
Project Structure:
TrainTicketSystem.java - Contains the main program and handles the train ticket booking process.
Purpose:
This project was created to practise Java programming by building a simple train ticket booking system. The problem it addresses is the problem of managing passenger and journey details, validating routes and calculating ticket costs and confirming bookings.
